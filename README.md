# inno-cmd-template
InnoSetup command-line utility installer template script. The script will create an installer for a 32bit program and append it to the **%PATH%** environment variable to be able to execute it from the command-line.

## How To

Clone repository.

    https://github.com/Amine-Belkacem/inno-cmd-template.git

Replace `myprog.exe` with your utility and `license.txt`  with your license.
Replace `readme.txt` content with your content. 
Adapt `script.iss` to your needs.
